# Monte Carlo Simulation of Academic Risk Under Typhoon Disruptions

## Dataset Notice

Large datasets and GIS shapefiles are excluded from this repository due to GitHub file size limitations.

Download the required datasets here:

[Google Drive Dataset Folder](https://drive.google.com/file/d/1ya5tO4XFe_tIX5gkNxzKemPqSAPUy000/view?usp=sharing)

After downloading, place the extracted files inside:

```text
data/
```

Required files include:
- `ibtracs.WP.list.v04r01.csv`
- `.shp`
- `.dbf`
- `.shx`
- `.prj`
- `.cpg`
